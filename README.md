# CNPMI

## Overview

This repository contains the implementation of a fundamental cross-lingual topic coherence metric (CNPMI)

## CNPMI 

CNPMI is a modified version for cross-lingual aligned topic automatic evaluation. 

## Reference Corpus

We use parallel cross-lingual referecne Wiki corpus.
